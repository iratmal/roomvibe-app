## 🧩 STRATEGY (READ FIRST)

This task is intentionally split into **PHASES inside ONE TASK**.

**Why one task?**

* All changes are UX‑connected (Artist flow → Public Profile → Artworks → Sales)
* Shared components & data models
* Easier to reason about edge cases

**Important:**

* Do NOT deploy to production
* Do NOT refactor unrelated code
* Do NOT introduce heavy abstractions

### UX improvement

* Add micro‑copy below indicator:

  > "Profiles with 100% completeness get more visibility"

---

## 2️⃣ “Your Public Profile” — Make It a HERO Element

### Current problem

* Looks like a normal input field
* Undervalues its importance

### Required changes

* Convert into a **highlighted card/box**
* Include:

  * Label: **Your Public Artist Page**
  * Short description:

    > "Share this page with collectors, designers and galleries"
  * Read‑only URL field
  * **Copy link** button

---

## 3️⃣ Public Visibility Per Artwork (CRITICAL)

### Problem

* Currently: If artist is visible → ALL artworks are public

### Solution

* Add per‑artwork toggle:

  * ☑ **Show on public profile**

### Rules

* Default: ON
* Stored per artwork
* Used by:

  * Public artist page
  * Designer/Gallery discovery

---

# PHASE 2 — ADD ARTWORK: MULTIPLE SIZE / PRICE VARIANTS

## 4️⃣ Artwork Variants (Print‑friendly)

### Key concept

* **Artwork = visual/motif**
* **Variant = size + price + availability**

---

### UI Changes (Add Artwork Form)

#### Default state (unchanged)

* One size
* One price

#### New toggle

☐ **This artwork is available in multiple sizes (prints / editions)**

---

### When toggle is ON

Replace single dimension fields with **Variant List**:

Each variant includes:

* Width
* Height
* Price
* Currency
* Availability (Available / Sold out / Limited)
* Optional Buy URL

UI example:

```
[ 150 x 100 cm ]  [ €550 ]  [ Available ]  [ Remove ]
+ Add another size
```

### Rules

* At least one variant required
* No artificial limit on number of variants (reasonable UI)

---

### Data Model (minimal extension)

* Artwork has:

  * variants: Variant[]

Variant fields:

* width
* height
* price
* currency
* availability
* buyUrl (optional)
