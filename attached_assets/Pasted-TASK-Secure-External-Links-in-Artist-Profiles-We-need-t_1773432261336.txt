TASK — Secure External Links in Artist Profiles

We need to improve the security and validation of external links that artists can add to their profiles.

Artists can currently add links such as:

Website

Instagram

Facebook

TikTok

LinkedIn

Pinterest

Etsy shop

These links appear on the public artist profile page, so we must ensure they are safe and properly handled.

1️⃣ External Link Security (Required)

All external links displayed on public artist profiles must include the following attributes:

target="_blank"
rel="nofollow noopener noreferrer"

Example:

<a href="https://instagram.com/artistname"
   target="_blank"
   rel="nofollow noopener noreferrer">
   Instagram
</a>

This prevents:

SEO authority transfer

tab hijacking

referral leaks

platform liability for external content

Apply this rule to all external profile links.

2️⃣ URL Sanitization (Required)

Before saving links to the database, validate and sanitize the URL.

Reject URLs that contain dangerous protocols:

❌ Do NOT allow:

javascript:
data:
file:

Allow only:

http://
https://

Example validation logic:

if (!url.startsWith("http://") && !url.startsWith("https://")) {
  rejectInput();
}
3️⃣ Domain Validation (Required)

Each social field must accept only its correct platform domain.

Instagram

Allowed:

instagram.com
www.instagram.com

Example validation:

https://instagram.com/username
https://www.instagram.com/username

Reject anything else.

Facebook

Allowed domains:

facebook.com
www.facebook.com
TikTok

Allowed domains:

tiktok.com
www.tiktok.com
LinkedIn

Allowed domains:

linkedin.com
www.linkedin.com
Pinterest

Allowed domains:

pinterest.com
www.pinterest.com
Etsy

Allowed domains:

etsy.com
www.etsy.com

Prefer URLs like:

https://etsy.com/shop/shopname
Website field

Website URL can be any valid domain, but still must pass:

http / https validation
4️⃣ Clean URL Storage

Normalize stored URLs.

If a user enters:

instagram.com/artist

Automatically convert to:

https://instagram.com/artist

before saving.

5️⃣ Error Messages

If validation fails, show a clear message.

Example:

Please enter a valid Instagram URL (instagram.com/yourusername)
6️⃣ Do NOT break existing data

Existing saved links should continue to work.

Validation applies only to:

new links

updated links

Expected Result

Artist profile links will now be:

safe

sanitized

domain-validated

SEO protected

protected from malicious protocols

while still allowing artists to promote their external sales channels.
