## 1️⃣ Buy URL – Global Only (REMOVE per-size Buy URL)

### Decision (final):

* **Buy URL exists ONLY once per artwork (global).**
* Individual size entries (prints / editions) must NOT contain Buy URL fields.

### Required changes:

* ❌ Remove **Buy URL (optional)** from:

  * “Available in multiple sizes (prints / editions)” section
  * All Size blocks (Size 1, Size 2, etc.)

### Final behaviour:

* All sizes inherit the **same global Buy URL**.
* If global Buy URL is empty:

  * “Contact Artist” is used for **all sizes**.

### Reason:

* Prevents artist confusion
* Covers 90% of real-world selling setups
* Keeps MVP clean and beginner-friendly
