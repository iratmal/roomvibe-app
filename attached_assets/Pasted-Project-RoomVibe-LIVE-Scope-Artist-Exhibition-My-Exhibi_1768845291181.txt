Project: RoomVibe (LIVE)
Scope: Artist → Exhibition (My Exhibition)

1️⃣ BUG: Upload Cover Image za Exhibition NE RADI

Problem:

U Artist Dashboard → My Exhibition

Klik na Edit Exhibition

U sekciji Cover Image:

“Choose Image” → odabir slike

Klik na Save Changes / Publish

❌ Slika se ne upload-a, nema promjene, nema errora u UI-ju

Expected behavior:

Cover image se mora:

uploadati u storage (isti bucket kao artwork images)

spremiti u exhibition record (coverImage / coverImageUrl)

odmah biti vidljiva nakon save-a

Agent provjeriti i popraviti:

API endpoint za update exhibition (PATCH/POST)

Da li endpoint:

prima multipart/form-data

prima coverImage kao file

Da li se koristi isti upload helper / storage logic kao za:

artwork images

Da li se coverImage URL pravilno sprema u DB

Da li frontend šalje file pod ispravnim key-em (coverImage, image, itd.)

2️⃣ BUG: Publish Exhibition NE RADI

Problem:

U Artist Dashboard → My Exhibition

Klik na Publish ili Publish Exhibition

UI ostaje u stanju:

“Exhibition not published”

❌ Status se ne mijenja

❌ Embed code se ne otključava

Expected behavior:

Klik na Publish Exhibition mora:

postaviti status = published

(ili isPublished = true)

omogućiti embed code

ukloniti warning “Exhibition not published”

Agent provjeriti i popraviti:

API endpoint za publish exhibition

Da li frontend:

uopće šalje request

šalje ispravan exhibition ID

Da li backend:

prima request

update-a publish status u DB

Da li frontend refresh-a state nakon uspješnog publisha

Artist ima samo jednu exhibition

Embed sekcija mora biti aktivna

Warning nestaje
