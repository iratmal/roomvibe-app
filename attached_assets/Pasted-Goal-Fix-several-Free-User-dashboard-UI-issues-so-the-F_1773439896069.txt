Goal:
Fix several Free/User dashboard UI issues so the Free plan clearly communicates what is and is not available.

Context:

This task applies ONLY to the Free/User dashboard.

Important rules:
- Do NOT modify Artist dashboard
- Do NOT modify Artist Pro dashboard
- Do NOT change plan logic or billing logic
- Do NOT redesign the full dashboard
- Keep existing layout and styling, only fix incorrect Free-plan UI behavior
- Use RoomVibe brand yellow instead of green where specified below

Scope:

1. Fix exhibition counter in top stats
Current problem:
The Free/User dashboard shows:

This is incorrect because Free/User does not have access to exhibitions.

Required fix:
Change this stat so it no longer implies the user has 1 available exhibition.

Preferred solution:

Free plan does not include exhibitions.

Do NOT leave:
